Manual de Operação (SIS v6)

📌 Controle de Seleção & Abas

• Shift + Clique: Seleção inteligente por intervalo de camadas.

• Ctrl + Clique: Seleção cumulativa unitária.

• Abas Estilo Chrome: Alterne abas na barra superior. Todo o progresso é guardado instantaneamente via LocalStorage.


🎬 Sistema de Containers de Cenas

• Selecione elementos e clique com o botão direito para Converter em Cena. O container gerado agrupa os itens. Se mover a cena, o conteúdo move-se junto. Use o olho (👁) no cabeçalho da cena para recolher/expandir o conteúdo de forma compacta.
