📌 Comandos Gerais & Seleções

• Duplo Clique no Fundo: Instancia uma Nota de Texto Livre (Post-it).

• Shift + Clique / Marquee: Adiciona ou remove múltiplos elementos da seleção na tela.

• Delete / Backspace: Remove definitivamente os elementos e imagens selecionadas.


🎬 Estruturas de Cena Dinâmicas

• Selecione elementos e clique em Agrupar Cena. O bloco gerado é claro e redimensionável. Arraste imagens para dentro de seus limites territoriais para incluí-las na cena; arraste-as para fora para removê-las da cena.


🔗 Rastreamento de Notas

• Use o botão direito para ligar notas a elementos através de linhas guia. O menu superior Elementos Vinculados abre um painel para gerenciar e quebrar esses vínculos cirurgicamente.
